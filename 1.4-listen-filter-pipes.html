Lektion 1.4 — Teil 1: Grundlagen

Listen, Filter & Pipes

Angular ca. 65 min Grundlagen

Lernziele

  • Listen mit @for, track und @empty anzeigen
  • @if/@else (mit as) und @switch einsetzen
  • Eingebaute Pipes wie date verwenden und importieren
  • Eine eigene Pipe mit ng generate pipe schreiben

1 — Kontrollstrukturen im Template

@for und @if haben wir schon kurz verwendet. Angular kennt im Template drei Kontrollstrukturen; sie sind fest eingebaut und müssen nicht importiert werden.

@for mit track und @empty

  • track flight.id ist Pflicht: Daran erkennt Angular jedes Element wieder und muss bei Änderungen nur die betroffenen Karten neu zeichnen – wie key in React.
  • @empty folgt direkt auf den @for-Block und erscheint, wenn die Liste leer ist – im FlugBoard, wenn die Suche nichts findet.
  • Innerhalb der Schleife gibt es Hilfsvariablen wie $index, $first oder $last.

@if mit @else und as

@else zeigt einen Block, wenn die Bedingung nicht zutrifft. Mit as flight bekommt der geprüfte Wert einen Namen: Innerhalb des Blocks ist flight sicher nicht null, das ?. aus Lektion 1.2 entfällt.

@switch

@switch wählt einen von mehreren Blöcken nach dem Wert eines Ausdrucks – wie switch in TypeScript, aber ohne break. Ein @default-Block ist möglich; fehlt er, wird bei keinem Treffer nichts angezeigt.

Die Auswahl-Box und die leere Liste in app.html:

src/app/app.html html 
<div class="page-content">
  <app-airport-header airportName="Wien" />

  <div class="toolbar">
    <!-- Two-Way-Binding: Eingabe und Signal bleiben synchron -->
    <input
      class="search-input"
      [(ngModel)]="searchText"
      placeholder="Flug, Airline, Airport ..."
    />

    <!-- Property-Binding auf eine CSS-Klasse + Event-Binding -->
    <div class="type-filter">
      <button [class.active]="activeType() === 'all'" (click)="activeType.set('all')">Alle</button>
      <button [class.active]="activeType() === 'departure'" (click)="activeType.set('departure')">
        Abflüge
      </button>
      <button [class.active]="activeType() === 'arrival'" (click)="activeType.set('arrival')">
        Ankünfte
      </button>
    </div>

    <span class="page-meta">{{ filteredFlights().length }} Treffer</span>
  </div>

  <div class="selected-info">
    @if (selectedFlight(); as flight) {
      <strong>Ausgewählt:</strong> {{ flight.flightNumber }} – {{ flight.airline }}
    } @else {
      Klicke auf einen Flug, um ihn auszuwählen.
    }
  </div>

  <div class="card-grid">
    @for (flight of filteredFlights(); track flight.id) {
      <app-flight-card [flight]="flight" (selected)="onFlightSelect($event)" />
    } @empty {

</div>

2 — Pipes: Werte für die Anzeige umwandeln

Eine Pipe formatiert einen Wert im Template: {{ wert | pipe }}. Argumente folgen nach einem Doppelpunkt: {{ today | date: 'dd.MM.yyyy' }}. Angular bringt Pipes für häufige Fälle mit, z. B. date, uppercase, number oder currency. Wie Komponenten müssen sie im imports-Array stehen – die date-Pipe heißt dort DatePipe.

src/app/airport-header/airport-header.ts typescript 
import { DatePipe } from '@angular/common';
import { Component, input } from '@angular/core';

@Component({
  imports: [DatePipe],
  selector: 'app-airport-header',
  styleUrl: './airport-header.css',
  templateUrl: './airport-header.html',
})
export class AirportHeader {
  // Input: Der Wert kommt von der Eltern-Komponente
  airportName = input.required<string>();
  today = new Date();
}
src/app/airport-header/airport-header.html html 
<h1 class="page-title">✈ FlugBoard {{ airportName() }}</h1>
<!-- Eingebaute Pipe mit Argument: Datumsformat -->
<p class="page-meta">{{ today | date: 'dd.MM.yyyy' }}</p>

3 — Eine eigene Pipe

Bisher zeigt das Abzeichen den internen Status-Code wie on-time. Eine eigene Pipe macht daraus lesbaren Text. Die CLI legt sie an:

Terminal bash 
ng generate pipe status-label
src/app/status-label-pipe.ts typescript 
import { Pipe, PipeTransform } from '@angular/core';
import { FlightStatus } from './flight';

@Pipe({
  name: 'statusLabel',
})
export class StatusLabelPipe implements PipeTransform {
  private readonly labels: Record<FlightStatus, string> = {
    'on-time': 'Pünktlich',
    delayed: 'Verspätet',
    boarding: 'Boarding',
    departed: 'Gestartet',
    landed: 'Gelandet',
    cancelled: 'Gestrichen',
  };

  // transform: Eingabewert → angezeigter Text
  transform(status: FlightStatus): string {
    return this.labels[status];
  }
}
  • name: 'statusLabel' ist der Name im Template: {{ flight().status | statusLabel }}.
  • transform bekommt den Wert links vom | und liefert den angezeigten Text.
  • Record<FlightStatus, string> verlangt für jeden Status einen Eintrag – fehlt einer, meldet TypeScript einen Fehler.

In FlightCard kommen die Pipe, @if für das Gate und @switch für statusabhängige Hinweise dazu:

src/app/flight-card/flight-card.ts typescript 
import { Component, input, output } from '@angular/core';
import { Flight } from '../flight';
import { StatusLabelPipe } from '../status-label-pipe';

@Component({
  imports: [StatusLabelPipe],
  selector: 'app-flight-card',
  styleUrl: './flight-card.css',
  templateUrl: './flight-card.html',
})
export class FlightCard {
  flight = input.required<Flight>();
  // Output: meldet der Eltern-Komponente, dass die Karte angeklickt wurde
  selected = output<Flight>();
}
src/app/flight-card/flight-card.html html 
<article class="flight-card" (click)="selected.emit(flight())">
  <div class="flight-card-head">
    <span class="flight-num">{{ flight().flightNumber }}</span>
    <!-- Eigene Pipe: Status-Code → lesbarer Text -->
    <span class="status-badge status-{{ flight().status }}">{{ flight().status | statusLabel }}</span>
  </div>
  <p class="flight-card-airline">{{ flight().airline }}</p>
  <p class="flight-card-meta">
    {{ flight().type === 'departure' ? '↑' : '↓' }} {{ flight().airport }}
  </p>
  <p class="flight-card-meta">
    {{ flight().scheduledTime }} · {{ flight().terminal }}
    @if (flight().gate) {
      · Gate {{ flight().gate }}
    }
  </p>

  <!-- @switch: je nach Status ein anderer Hinweis -->
  @switch (flight().status) {
    @case ('delayed') {
      <p class="time-delayed">Neue Zeit: {{ flight().expectedTime }}</p>
    }
    @case ('boarding') {
      <p class="flight-card-meta">Boarding läuft</p>
    }
    @case ('cancelled') {
      <p class="flight-card-meta">Flug gestrichen</p>
    }
  }
</article>

Projektschritt

Projektschritt 1.4

Status-Texte, Hinweise und leere Liste

  1. app.html: @empty an die Kartenliste hängen, Auswahl-Box mit @if … as und @else (Abschnitt 1)
  2. AirportHeader: Datum mit der date-Pipe anzeigen (Abschnitt 2)
  3. StatusLabelPipe mit ng generate pipe anlegen (Abschnitt 3)
  4. FlightCard: Pipe importieren und verwenden, Gate mit @if, Hinweise mit @switch
  5. Testen: Suche nach „xyz“ zeigt „Keine Flüge gefunden.“

Häufige Fehler

@for ohne track

Der Compiler meldet einen Fehler: track ist bei @for Pflicht.

Fix: Eine eindeutige Eigenschaft angeben: track flight.id.

No pipe found with name 'statusLabel'

Die Pipe ist angelegt, steht aber nicht im imports-Array der Komponente, die sie verwendet.

Fix: In flight-card.ts: imports: [StatusLabelPipe]. Gleiches gilt für eingebaute Pipes wie DatePipe.

@empty an der falschen Stelle

@empty steht in einem eigenen Block statt direkt nach der schließenden Klammer von @for.

Fix: } @empty { – der Block gehört unmittelbar zu @for, wie @else zu @if.

Aufgaben

Aufgabe 1 FlightTypePipe

Schreibe eine Pipe flightType, die aus departure/arrival den Text „↑ Abflug“ bzw. „↓ Ankunft“ macht, und ersetze damit den Bedingungsoperator in der Karte.

Aufgabe 2 Pipe mit Argument

Erweitere statusLabel um ein optionales Argument kurz: {{ status | statusLabel: true }} liefert nur ein Symbol (✓, ⏱, ✕ …). Das Argument kommt als zweiter Parameter in transform an.

Aufgabe 3 Nummerierung mit $index

Zeige vor jeder Karte ihre Position in der gefilterten Liste an (1, 2, 3 …). Verwende $index; der Index beginnt bei 0.

Bonus Verspätung in Minuten

Eine Pipe delayMinutes bekommt einen Flug und liefert z. B. „+30 min“ aus scheduledTime und expectedTime. Verwende sie im @case ('delayed').

Quiz

5 Fragen · zum Aufklappen klicken

Frage 1 Was ist bei @for Pflicht?

Erklärung: Über track erkennt Angular, welche Einträge gleich geblieben sind – vergleichbar mit key in React.

Frage 2 Wo steht der @empty-Block?

Erklärung: @empty gehört zu @for wie @else zu @if und wird angezeigt, wenn die Liste leer ist.

Frage 3 Was bewirkt @if (selectedFlight(); as flight) { … }?

Erklärung: Mit as bekommt der geprüfte Wert einen Namen; das ?. ist im Block nicht mehr nötig.

Frage 4 Was zeigt {{ today | date: 'dd.MM.yyyy' }} an?

Erklärung: Eine Pipe formatiert einen Wert im Template; Argumente folgen nach dem Doppelpunkt. DatePipe muss importiert sein.

Frage 5 „No pipe found with name 'statusLabel'“ – woran liegt es?

Erklärung: Wie Komponenten müssen auch eigene und eingebaute Pipes importiert werden, z. B. imports: [StatusLabelPipe].
