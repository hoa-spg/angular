Projektidee: FlugBoard

Im Mittelpunkt dieses Kurses steht das Projekt FlugBoard — eine Echtzeit-Fluganzeigetafel ähnlich einem Abflug-/Ankunftsmonitor an einem realen Flughafen. Die App wird in jeder Lektion um neue Angular-Konzepte und Features erweitert, sodass am Ende eine vollständige Single-Page-Application mit API-Anbindung, Routing, Reactive Forms und einem persistenten Backend entstehen.

Das Backend ist ein schlanker Deno + Hono-Server mit Drizzle ORM und SQLite-Datenbank. Ab Lektion 2.2 wird das Frontend an dieses Backend angebunden; ab Lektion 2.4 ist das Fullstack-Projekt komplett.

Voraussetzungen

ℹ
Empfohlenes Vorwissen

HTML & CSS Grundlagen, JavaScript (ES6+: Arrow Functions, Destructuring, Spread, Promises/async-await), TypeScript Basics (Interfaces, Generics, Union Types), HTTP-Methoden (GET, POST, PATCH, DELETE).

✓
Empfohlene Tools

Visual Studio Code mit den Extensions Angular Language Service, ESLint und Prettier. Node.js ≥ 18, Deno ≥ 1.40, Git, Angular CLI (npm install -g @angular/cli).

⚠
Angular-Version in diesem Kurs

Dieser Kurs verwendet Angular 17+ mit der neuen Control Flow Syntax (@for, @if, @switch) und der Standalone-Komponenten-API. Ältere Konzepte wie NgModule und *ngFor/*ngIf werden zum Verständnis erklärt, aber nicht als primärer Ansatz verwendet.

Lokaler Test

Dieser Kurs ist als statische HTML-Seiten konzipiert und läuft direkt im Browser — ohne Build-Schritt. Alle Pfade sind relativ, sodass er auf GitHub Pages, einem lokalen Webserver oder per Doppelklick auf die HTML-Dateien funktioniert.

Lokaler Test bash 
# Mit Python (kein Install nötig)
python3 -m http.server 8080
# → http://localhost:8080/angular/index.html

# Mit Node.js
npx serve .
# → http://localhost:3000
