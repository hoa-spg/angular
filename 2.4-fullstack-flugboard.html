Angular Router — Client-Side Routing

Der Angular Router ermöglicht Navigation zwischen verschiedenen Ansichten, ohne die Seite neu zu laden. Jede Route wird einer Komponente zugeordnet. Der Router rendert die aktive Komponente in <router-outlet>.

src/app/app.routes.ts typescript 
import { Routes } from '@angular/router';

export const routes: Routes = [
  {
    path: '',
    redirectTo: 'flights',
    pathMatch: 'full',
  },
  {
    path: 'flights',
    // Lazy Loading: Komponente wird erst geladen, wenn Route besucht wird
    loadComponent: () =>
      import('./pages/flight-board/flight-board.component').then(
        m => m.FlightBoardComponent,
      ),
    data: { title: 'Flugbord Wien' },
  },
  {
    path: 'flights/:id',
    loadComponent: () =>
      import('./pages/flight-detail/flight-detail.component').then(
        m => m.FlightDetailComponent,
      ),
  },
  {
    path: 'flights/new',
    loadComponent: () =>
      import('./pages/add-flight/add-flight.component').then(
        m => m.AddFlightComponent,
      ),
  },
  {
    path: '**',
    loadComponent: () =>
      import('./pages/not-found/not-found.component').then(
        m => m.NotFoundComponent,
      ),
  },
];
ℹ
Lazy Loading — Vorteile

Mit loadComponent wird der JavaScript-Code einer Route erst heruntergeladen, wenn der Nutzer diese Route besucht. Das bedeutet: Kleineres initiales Bundle, schnelleres erstes Laden. Besonders bei großen Apps (viele Seiten) macht Lazy Loading einen erheblichen Performance-Unterschied.

Route-Parameter — ActivatedRoute

Wenn die Route /flights/:id aufgerufen wird, enthält :id den Wert aus der URL. ActivatedRoute gibt Zugriff auf diese Parameter.

src/app/pages/flight-detail/flight-detail.component.ts typescript 
import { Component, inject, OnInit } from '@angular/core';
import { ActivatedRoute, Router }    from '@angular/router';
import { FlightApiService }          from '../../services/flight-api.service';
import { Flight }                    from '../../models/flight';
import { AsyncPipe }                 from '@angular/common';
import { Observable, switchMap }     from 'rxjs';

@Component({
  selector: 'app-flight-detail',
  standalone: true,
  imports: [AsyncPipe],
  template: `
    @if (flight$ | async; as flight) {
      <article class="flight-detail">
        <header>
          <h2>{{ flight.flightNumber }}</h2>
          <p>{{ flight.airline }}</p>
        </header>
        <dl class="flight-data">
          <dt>Typ</dt>
          <dd>{{ flight.type === 'departure' ? 'Abflug' : 'Ankunft' }}</dd>
          <dt>Geplante Zeit</dt>
          <dd>{{ flight.scheduledTime }}</dd>
          <dt>Status</dt>
          <dd>{{ flight.status }}</dd>
          <dt>Flughafen</dt>
          <dd>{{ flight.airport }}</dd>
          <dt>Terminal</dt>
          <dd>{{ flight.terminal }}</dd>
          @if (flight.gate) {
            <dt>Gate</dt>
            <dd>{{ flight.gate }}</dd>
          }
        </dl>
        <div class="actions">
          <button (click)="onDelete(flight.id)">Flug löschen</button>
          <a [routerLink]="['/flights']">← Zurück</a>
        </div>
      </article>
    } @else {
      <p>Lade Flugdaten...</p>
    }
  `,
})
export class FlightDetailComponent implements OnInit {
  private route     = inject(ActivatedRoute);
  private flightApi = inject(FlightApiService);
  private router    = inject(Router);

  flight$!: Observable<Flight>;

  ngOnInit(): void {
    // Observable-Variante: reagiert auf URL-Änderungen ohne Neurendern
    this.flight$ = this.route.paramMap.pipe(
      switchMap(params => {
        const id = Number(params.get('id'));
        return this.flightApi.getFlightById(id);
      }),
    );
  }

  onDelete(id: number): void {
    this.flightApi.deleteFlight(id).subscribe(() => {
      this.router.navigate(['/flights']);  // zurück zur Liste
    });
  }
}

Reactive Forms — typsicheres Formular-Handling

Angular bietet zwei Formular-Ansätze: Template-Driven (mit ngModel, einfach, wenig Code) und Reactive Forms (mit FormBuilder, typsicher, gut testbar). Für komplexe Formulare mit Validierung sind Reactive Forms die empfohlene Wahl.

src/app/pages/add-flight/add-flight.component.ts typescript 
import { Component, inject }              from '@angular/core';
import { Router }                          from '@angular/router';
import { ReactiveFormsModule,
         FormBuilder, Validators,
         AbstractControl }                 from '@angular/forms';
import { FlightApiService }               from '../../services/flight-api.service';

@Component({
  selector: 'app-add-flight',
  standalone: true,
  imports: [ReactiveFormsModule],
  template: `
    <form [formGroup]="form" (ngSubmit)="onSubmit()" class="flight-form">
      <h2>Neuen Flug hinzufügen</h2>

      <div class="form-group">
        <label for="flightNumber">Flugnummer *</label>
        <input
          id="flightNumber"
          formControlName="flightNumber"
          placeholder="z.B. OS123"
          [class.invalid]="isInvalid('flightNumber')"
        >
        @if (isInvalid('flightNumber')) {
          <span class="error">
            @if (form.get('flightNumber')?.errors?.['required']) {
              Flugnummer ist erforderlich.
            }
            @if (form.get('flightNumber')?.errors?.['pattern']) {
              Format: 2 Buchstaben + 1-4 Ziffern (z.B. OS123).
            }
          </span>
        }
      </div>

      <div class="form-group">
        <label for="airline">Airline *</label>
        <input id="airline" formControlName="airline"
               [class.invalid]="isInvalid('airline')">
        @if (isInvalid('airline')) {
          <span class="error">Airline-Name ist erforderlich.</span>
        }
      </div>

      <div class="form-group">
        <label for="type">Typ *</label>
        <select id="type" formControlName="type">
          <option value="departure">Abflug</option>
          <option value="arrival">Ankunft</option>
        </select>
      </div>

      <div class="form-group">
        <label for="scheduledTime">Geplante Zeit *</label>
        <input id="scheduledTime" type="time" formControlName="scheduledTime"
               [class.invalid]="isInvalid('scheduledTime')">
        @if (isInvalid('scheduledTime')) {
          <span class="error">Zeit ist erforderlich.</span>
        }
      </div>

      <div class="form-group">
        <label for="airport">Flughafen *</label>
        <input id="airport" formControlName="airport"
               placeholder="z.B. Berlin BER"
               [class.invalid]="isInvalid('airport')">
      </div>

      <div class="form-group">
        <label for="terminal">Terminal *</label>
        <input id="terminal" formControlName="terminal" placeholder="z.B. T2">
      </div>

      <div class="form-group">
        <label for="gate">Gate (optional)</label>
        <input id="gate" formControlName="gate" placeholder="z.B. B12">
      </div>

      <div class="form-actions">
        <button type="submit" [disabled]="form.invalid || isSubmitting">
          {{ isSubmitting ? 'Wird gespeichert...' : 'Flug hinzufügen' }}
        </button>
        <a [routerLink]="['/flights']">Abbrechen</a>
      </div>
    </form>
  `,
})
export class AddFlightComponent {
  private fb        = inject(FormBuilder);
  private flightApi = inject(FlightApiService);
  private router    = inject(Router);

  isSubmitting = false;

  form = this.fb.group({
    flightNumber:  ['', [
      Validators.required,
      Validators.pattern(/^[A-Z]{2}\d{1,4}$/),  // z.B. OS123
    ]],
    airline:       ['', Validators.required],
    type:          ['departure' as 'departure' | 'arrival'],
    scheduledTime: ['', Validators.required],
    airport:       ['', Validators.required],
    terminal:      ['T1', Validators.required],
    gate:          [''],
    status:        ['on-time'],
  });

  /** Gibt zurück, ob ein Feld invalid UND bereits berührt wurde */
  isInvalid(fieldName: string): boolean {
    const control: AbstractControl | null = this.form.get(fieldName);
    return !!(control && control.invalid && control.touched);
  }

  onSubmit(): void {
    if (this.form.invalid) {
      this.form.markAllAsTouched();  // alle Felder als "berührt" markieren
      return;
    }

    this.isSubmitting = true;
    const value = this.form.value;

    this.flightApi.createFlight({
      flightNumber:  value.flightNumber  ?? '',
      airline:       value.airline       ?? '',
      type:          value.type          as 'departure' | 'arrival',
      scheduledTime: value.scheduledTime ?? '',
      airport:       value.airport       ?? '',
      terminal:      value.terminal      ?? 'T1',
      gate:          value.gate          || undefined,
      status:        value.status        as any,
    }).subscribe({
      next: () => this.router.navigate(['/flights']),
      error: err => {
        console.error('Fehler beim Speichern:', err);
        this.isSubmitting = false;
      },
    });
  }
}

Backend: Deno + Hono + Drizzle + SQLite

Das Backend ist ein schlanker REST-API-Server auf Basis von Deno (modernes, sicheres JavaScript-Runtime), Hono (minimales Web-Framework), Drizzle ORM (TypeScript-first ORM) und SQLite (embedded DB).

backend/main.ts typescript 
import { Hono }    from 'hono';
import { cors }    from 'hono/cors';
import { serve }   from '@hono/node-server';  // oder Deno serve
import {
  getAllFlights,
  getFlightById,
  createFlight,
  deleteFlight,
  patchStatus,
} from './db.ts';

const app = new Hono();

// CORS für Angular-Dev-Server freigeben:
app.use('*', cors({
  origin: 'http://localhost:4200',
  allowMethods: ['GET', 'POST', 'PATCH', 'DELETE'],
}));

// GET /api/flights – alle Flüge
app.get('/api/flights', async (c) => {
  const flights = await getAllFlights();
  return c.json(flights);
});

// GET /api/flights/:id – ein Flug
app.get('/api/flights/:id', async (c) => {
  const id     = Number(c.req.param('id'));
  const flight = await getFlightById(id);
  if (!flight) return c.json({ error: 'Not found' }, 404);
  return c.json(flight);
});

// POST /api/flights – neuen Flug anlegen
app.post('/api/flights', async (c) => {
  const body   = await c.req.json();
  const flight = await createFlight(body);
  return c.json(flight, 201);
});

// PATCH /api/flights/:id/status – Status aktualisieren
app.patch('/api/flights/:id/status', async (c) => {
  const id     = Number(c.req.param('id'));
  const { status } = await c.req.json();
  const flight = await patchStatus(id, status);
  return c.json(flight);
});

// DELETE /api/flights/:id – Flug löschen
app.delete('/api/flights/:id', async (c) => {
  const id = Number(c.req.param('id'));
  await deleteFlight(id);
  return c.json({ success: true });
});

// Server starten:
serve({ fetch: app.fetch, port: 8000 }, info => {
  console.log(`Backend läuft auf http://localhost:${info.port}`);
});
backend/db.ts — Drizzle ORM Schema & Queries typescript 
import { drizzle }       from 'drizzle-orm/better-sqlite3';
import Database           from 'better-sqlite3';
import { sqliteTable,
         integer, text } from 'drizzle-orm/sqlite-core';
import { eq }            from 'drizzle-orm';

// Datenbank initialisieren:
const sqlite = new Database('flugboard.db');
const db     = drizzle(sqlite);

// Schema definieren:
export const flights = sqliteTable('flights', {
  id:            integer('id').primaryKey({ autoIncrement: true }),
  flightNumber:  text('flight_number').notNull(),
  airline:       text('airline').notNull(),
  type:          text('type', { enum: ['arrival', 'departure'] }).notNull(),
  scheduledTime: text('scheduled_time').notNull(),
  expectedTime:  text('expected_time'),
  status:        text('status', {
    enum: ['on-time', 'delayed', 'boarding', 'departed', 'landed', 'cancelled'],
  }).notNull().default('on-time'),
  airport:       text('airport').notNull(),
  terminal:      text('terminal').notNull(),
  gate:          text('gate'),
});

// Tabelle erstellen (einmalig, idempotent):
sqlite.exec(`
  CREATE TABLE IF NOT EXISTS flights (
    id             INTEGER PRIMARY KEY AUTOINCREMENT,
    flight_number  TEXT    NOT NULL,
    airline        TEXT    NOT NULL,
    type           TEXT    NOT NULL CHECK(type IN ('arrival','departure')),
    scheduled_time TEXT    NOT NULL,
    expected_time  TEXT,
    status         TEXT    NOT NULL DEFAULT 'on-time',
    airport        TEXT    NOT NULL,
    terminal       TEXT    NOT NULL,
    gate           TEXT
  )
`);

// CRUD-Operationen:
export const getAllFlights  = () =>
  db.select().from(flights).all();

export const getFlightById = (id: number) =>
  db.select().from(flights).where(eq(flights.id, id)).get();

export const createFlight  = (data: Omit<typeof flights.$inferInsert, 'id'>) =>
  db.insert(flights).values(data).returning().get();

export const deleteFlight  = (id: number) =>
  db.delete(flights).where(eq(flights.id, id)).run();

export const patchStatus   = (id: number, status: string) =>
  db.update(flights)
    .set({ status: status as any })
    .where(eq(flights.id, id))
    .returning().get();

Häufige Fehler

Cannot find module 'better-sqlite3' im Deno-Backend

Das npm-Paket better-sqlite3 benötigt native Node.js-Addons und ist nicht direkt Deno-kompatibel. Mit dem Deno-Node-Compatibility-Layer läuft es oft, aber nicht immer.

Fix: Entweder npm statt Deno als Runtime verwenden (node main.js), oder auf @db/sqlite (Deno-native) umstellen und das Drizzle-Adapter entsprechend anpassen.

CORS-Fehler auch mit cors()-Middleware

CORS wird oft falsch konfiguriert: Preflight-Requests (OPTIONS) werden nicht korrekt behandelt, oder die origin-Option passt nicht.

Fix: Im Backend app.use('*', cors()) ohne Einschränkungen für die Entwicklung. In Produktion auf die konkrete Domain beschränken. Prüfe im Browser-Netzwerk-Tab, ob der OPTIONS-Preflight-Request eine 200-Antwort mit den richtigen Headern bekommt.

Can't bind to 'formGroup' since it isn't a known property

ReactiveFormsModule fehlt im imports-Array der Standalone-Komponente.

Fix: import { ReactiveFormsModule } from '@angular/forms'; und imports: [ReactiveFormsModule] in der Formular-Komponente hinzufügen.

ActivatedRoute-Parameter gibt null zurück

this.route.snapshot.paramMap.get('id') gibt null, wenn die Route keinen :id-Parameter hat oder der Name falsch geschrieben ist.

Fix: Routen-Konfiguration prüfen: der Parameter muss exakt als :id in app.routes.ts definiert sein. console.log(this.route.snapshot.params) zeigt alle verfügbaren Parameter.

Aufgaben

Aufgabe 1 Status-Änderung direkt in der Liste

Füge in FlightCardComponent ein <select>-Element hinzu, über das der Status eines Flugs direkt geändert werden kann (ohne die Detail-Seite aufzurufen). Der Wert soll per PATCH /api/flights/:id/status an das Backend gesendet werden. Nutze switchMap, damit parallele Klicks sicher behandelt werden.

Aufgabe 2 Route Guard implementieren

Erstelle einen canDeactivate-Guard für AddFlightComponent: Wenn das Formular verändert (form.dirty === true), aber noch nicht gespeichert wurde, soll beim Navigieren weg ein Bestätigungsdialog erscheinen (confirm('Änderungen verwerfen?')). Implementiere das als CanDeactivateFn-Funktion und binde sie in die Route ein.

Aufgabe 3 Pagination

Implementiere eine einfache Paginierung für die Flugliste: Pro Seite werden maximal 10 Flüge angezeigt. Baue Vor/Zurück-Buttons und einen Seiten-Indikator. Integriere die Seiten-Nummer als Query-Parameter in die URL: /flights?page=2. Lies den Parameter über this.route.queryParamMap.

Aufgabe 4 Optimistic UI Update

Implementiere beim Löschen eines Flugs ein Optimistic UI Update: Entferne den Flug sofort aus der lokalen Liste (ohne auf die API zu warten). Wenn der API-Aufruf fehlschlägt, stelle die ursprüngliche Liste wieder her und zeige eine Fehlermeldung. Nutze catchError im RxJS-Stream.
